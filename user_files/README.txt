PronounceIt stores user-created pronunciation lists in this folder.

Anki preserves user_files when the add-on is upgraded.

Generated fallback audio clips are cached in user_files/generated_audio.
Downloaded comprehensive audio shards are stored in user_files/audio_packs.
Requested pack clips are extracted into the size-limited user_files/audio_cache.
Valid saved/custom JSON files are updated atomically and the prior version is kept as a .bak backup.
