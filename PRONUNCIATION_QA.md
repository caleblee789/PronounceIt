# Pronunciation validation

This release provides AI-generated pronunciation audio from OpenAI Realtime (gpt-realtime-2.1-mini, Marin).

The ten original pilot recordings were accepted by listening. All 98,305 packaged recordings passed file and audio-signal checks. The hosted library and included written guides are bound by exact inventory and manifest checksums. Whole-library linguistic accuracy was not measured.

The online add-on downloads the separate complete audio library through PronounceIt settings. The private offline installer was separately validated before this online package was derived from its exact approved runtime, guides, and recordings.
