# PronounceIt 1.4.0 · Marin pronunciation library

PronounceIt adds written pronunciation guides and audio playback to Anki desktop. This release includes 98,305 written guides and provides matching AI-generated recordings using OpenAI Realtime (gpt-realtime-2.1-mini, Marin).

Install pronounceit.ankiaddon through Tools > Add-ons > Install from file, then restart Anki. Install over PronounceIt to retain its settings, saved pronunciations, and custom corrections.

Written guides are available immediately. Open PronounceIt settings > Audio > Download library to download the complete audio library. The download manages its 16 checksum-verified files automatically and can be paused and resumed. The audio library requires approximately 1 GB of download space, plus room for playback caching.

The recordings are provided as downloadable files; users do not need an OpenAI account or API key. Your computer voice remains available according to your playback settings.
